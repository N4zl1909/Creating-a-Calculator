# Simple Counter Application

A lightweight and interactive web-based counter application created with HTML, CSS, and JavaScript.

## Features

- **Increase Counter:** Increments the current value by 1.
- **Reset Counter:** Resets the value back to 0.
- **Decrease Counter:** Decrements the current value by 1.
- Clean and minimalistic user interface.

## Technologies Used

- **HTML5** - Markup structure
- **CSS3** - Styling and layout
- **JavaScript** - Interactive logic and state management

## Getting Started

1. Clone or download this repository to your local machine.
2. Open `Counter.html` directly in any web browser.
3. Use the buttons to interact with the counter!
